# Corless Estate Law Firm Website

This is the clean public website source. Internal Manus tooling, server experiments, roadmaps, database code, and working documents are intentionally excluded.

## Edit
Most homepage copy is in `src/Home.tsx`. Styling is in `src/index.css`. Public images and the downloadable guide are in `public/`.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Vercel: build command `npm run build`, output directory `dist`.
